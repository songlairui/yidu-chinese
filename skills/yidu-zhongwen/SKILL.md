# 易读中文

## 规则
1. 主谓清晰：每句先找「谁做了什么」。主语缺失或被抽象名词顶替时，补回真实主语（原文有的才补）。
2. 拟人、比喻改平实：「数据击穿认知」→「数据和之前的看法不一致」。非生物主语配比喻动词（击穿、撬动、打磨、沉淀）优先改写。
3. 不加原文没有的信息：不补数字、原因、例子、结论。
4. 数字、否定、范围词（至少、最多、约、未）不变。
5. 少用加粗和装饰：整篇加粗不超过几处；删去无信息的开场与总结套话。
6. 「不是…而是…」只在确有对比时用。
7. 一句一个意思，过长句（约 60 字以上）拆开。

## 复述检验（对应原项目的「言い直しテスト」）
改完后，把每句用最朴素的话再说一遍，与修改前逐句对照：事实、数字、否定、范围是否一致？不一致就回退该句。无法复述清楚的句子，说明原文本身含糊，标出来问作者，不要猜。

## 流程
1. 运行 `python3 scripts/yidu_lint.py 原文` 取得命中行。
2. 按规则改写，保留原意。
3. 再跑一次 lint，并做复述检验。
4. 输出：改后文本 + 改动摘要 + 存疑点。

注：lint 只是线索，命中不等于错，未命中也不等于好文。
